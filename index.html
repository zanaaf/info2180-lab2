What is HTML?

October 3, 2026 by Zanaa Ferguson

HTML, also known as HyperText Markup Language, was created in 1989 by Tim Berners-Lee while he worked at CERN. It is the standard markup language used when creating webpages. It exists to define the structure of a webpage, while CSS defines the look of the page and JavaScript defines the behavior of the page. It defines the structure of the page through its elements, called tags, telling the browser how to display the content.

These tags also act as labels, telling the browser what it is. Examples of labels given to tags are headings 1 through 6, paragraphs, line breaks, images, etc. The structure of HTML is <tagname> content </tagname>; e.g. <h1> Hello! </h1>, which will create a heading of the highest importance. HTML documents are usually saved with a .html extension. Come back next post for more information on HTML before we move onto Cascading Style Sheets!

What is Web Development?

October 1, 2026 by Zanaa Ferguson

Web Development is the process of creating and maintaing websites on the Internet. The World Wide Web is a global system of interconnected webpages accessible through the Internet. This was created by Tim-Berners Lee in 1989 in order to solve the issue of his frustration of having to log into different systems to retrieve data at CERN in Switzerland. In order to automate the process, he connected informations across different computers using hypertext, which is text with links, to simplify the retrieval process.

There are 2 major areas in Web Development, frontend and backend. These two modules form the backbone of Web Dev. Frontend covers client-side experiences and include technologies that are used to structure, style and make web pages interactive. This includes HTML, CSS, JavaScript. On the other end, backend development focuses on code that's used server-side. Examples of backend technologies are Node.js, PHP, Python, Ruby and many others.
